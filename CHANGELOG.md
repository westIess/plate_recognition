# Изменения

- Явные компоненты OpenCV, условные geometry/xobjdetect для 5.x,
  необязательный каскад, imported pkg-config targets Tesseract/Leptonica.
- Общий заголовок совместимости вместо opencv.hpp.
- Постобработка формата РФ, позиционные исправления и выбор с приоритетом
  валидности; невалидные результаты не выдаются как распознанный номер.
- Perspective warp по контуру из четырёх углов; безопасный fallback.
- Детекция контурами даже при срабатывании Haar, удаление дублей по IoU.
- Два варианта бинаризации, корректная обработка ошибки Tesseract Init.
- Отладочные боксы, вырезки, warp, бинаризации и текстовые логи OCR.
- evaluate, Levenshtein, accuracy, CER, CSV ошибок и эталонная разметка.
  Эти утилиты отсутствовали в предоставленном архиве и добавлены заново.
- Корректное экранирование CSV, диагностика ошибок файлов и коды выхода.
- Исправлен генератор синтетики: типы шума, перспективный наклон без
  обрезания, разметка вместе с кадрами.
- CTest, автономные тесты строк/метрик и тесты геометрии.
- Инструкции Linux/MSYS2, скрипт UCRT64, CMake-задачи VS Code.
- Старый output/results.csv перенесён в tests/legacy_results.csv.

Статус проверок и ограничения — в VALIDATION.md.

## Исправления по результатам пользовательского прогона

- Контурные кандидаты идут перед каскадными. При IoU-дедупликации
  контурный бокс больше не вытесняется каскадным; при ограничении числа
  OCR-кандидатов сначала рассматриваются контуры.
- Добавлен Dockerfile: копирует tests/ для CTest и ground_truth.csv
  из корня; CMD использует этот же путь. По умолчанию Docker запускает
  контурный режим без каскада.
- Добавлена проверка сохранения контурного префикса на трёх исходных
  кадрах при включении каскада (CTest geometry).
